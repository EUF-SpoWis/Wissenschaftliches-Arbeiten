# Melinas Option 1:

## Check-up: Qualitative Inhaltsanalyse
 
Mit diesem Check-up kannst du selbst prüfen, ob du das Codieren mit einem vorgegebenen Kategoriensystem sicher anwenden kannst.
 
Du bekommst einen kurzen Ausschnitt aus einem Interview mit einem Kind aus dem Volleyballtraining. Deine Aufgabe: Ordne die **Aussagen des Kindes** jeweils einer Kategorie aus dem Kategoriensystem zu.
 
> **Hinweis:** Die Zuordnung ist nicht immer eindeutig. Nutze die Musterlösung als Orientierung und Anregung für den Vergleich im Plenum, nicht als "die einzig richtige" Antwort.
 
### Kategoriensystem (Kodierleitfaden)
 
Grundlage ist die Forschungsfrage: *Welche Bedingungen und Handlungen erleben Kinder im Training als förderlich für ihr eigenes Kompetenzerleben?*
 
| Kategorie | Definition | Ankerbeispiel | Kodierregel |
|-----------|------------|---------------|-------------|
| **K1: Rückmeldung durch die Trainerin** | Aussagen, in denen das Kind eine Rückmeldung (Lob, Korrektur, Hinweis) der Trainerin schildert und als förderlich für das eigene Können erlebt. | "Der Trainer hat gesagt, dass ich mich verbessert habe." | Codiere, wenn die Rückmeldung von der Trainerin oder dem Trainer ausgeht und einen Bezug zum eigenen Können hat. |
| **K2: Passung der Aufgaben** | Aussagen dazu, wie gut die Übungsanforderungen zum eigenen Können passen (zu leicht, zu schwer, genau richtig). | "Die Übung war genau schwer genug, dass ich mich anstrengen musste." | Codiere, wenn der Schwierigkeitsgrad der Aufgabe im Mittelpunkt steht. |
| **Nicht zuordenbar** | Aussagen, die zu keiner der beiden Kategorien passen. | | Codiere hier alles, was für die Forschungsfrage keine Rolle spielt. |
 
### Aufgabe: Interviewausschnitt codieren
 
Lies den Ausschnitt und ordne jede Aussage des Kindes einer Kategorie zu. Die Fragen der Interviewerin dienen nur als Kontext und werden nicht codiert.
 
---
 
**Interviewerin:** Erzähl doch mal, wie war das gestern im Training für dich?
 
**Lea:** Eigentlich ganz gut. Am Anfang hat die Trainerin gesagt, dass mein Aufschlag schon viel sicherer geworden ist. Das hat mich richtig gefreut, weil ich da vorher immer Probleme hatte.
 
**Aussage 1 gehört zu:**
 
[[ Passung der Aufgaben | Nicht zuordenbar | (K1: Rückmeldung durch die Trainerin) ]]
[[?]] Wer spricht in der Aussage über das eigene Können, und von wem kommt die Aussage darüber?
***
**Musterlösung: K1 (Rückmeldung durch die Trainerin).**
 
Die Trainerin gibt eine Rückmeldung zum Aufschlag ("viel sicherer geworden"), und Lea erlebt diese als positiv für ihr Können. Beide Teile der Kodierregel sind erfüllt.
***
 
---
 
**Interviewerin:** Und wie waren dann die Übungen für dich?
 
**Lea:** Manche waren zu leicht. Da haben wir nur den Ball hin- und hergespielt, und ich hab gar nicht gemerkt, dass ich besser werde. Aber bei den Spielen, wo man sich richtig anstrengen muss, merk ich, dass ich was kann.
 
**Aussage 2 gehört zu:**
 
[[ (K2: Passung der Aufgaben) | K1: Rückmeldung durch die Trainerin | Nicht zuordenbar ]]
[[?]] Worüber spricht Lea hier: über eine Rückmeldung oder über die Übungen selbst?
***
**Musterlösung: K2 (Passung der Aufgaben).**
 
Im Mittelpunkt steht der Schwierigkeitsgrad der Übungen: "zu leicht" versus "richtig anstrengen". Lea beschreibt, dass sie ihr Können vor allem dann spürt, wenn die Anforderung passt. Eine Rückmeldung der Trainerin kommt hier nicht vor.
***
 
---
 
**Interviewerin:** Was ist dir sonst noch aufgefallen?
 
**Lea:** Nach dem Training sind die Lena und ich noch zusammen zur Bushaltestelle gelaufen. Wir waren schon ziemlich müde.
 
**Aussage 3 gehört zu:**
 
[[ K1: Rückmeldung durch die Trainerin | K2: Passung der Aufgaben | (Nicht zuordenbar) ]]
[[?]] Trägt diese Aussage etwas zur Forschungsfrage bei?
***
**Musterlösung: Nicht zuordenbar.**
 
Die Aussage beschreibt den Heimweg nach dem Training und hat keinen Bezug zu Rückmeldung oder Aufgabenschwierigkeit. Für die Forschungsfrage ist sie in diesem Kategoriensystem nicht relevant.
 
*Anmerkung für das Plenum:* In einem vollständigen Kategoriensystem könnte hier etwa "soziale Eingebundenheit" eine eigene Kategorie sein. Das hängt vom theoretischen Rahmen ab (z. B. Selbstbestimmungstheorie).
***
 
---
 
### Zum Weiterdenken (Plenum)
 
- Bei welcher Aussage warst du unsicher, und woran lag das?
- Gab es Stellen, an denen dir eine Kategorie gefehlt hat? Was würde das für das Kategoriensystem bedeuten?
- Wie würdet ihr vorgehen, wenn zwei Codierende dieselbe Aussage unterschiedlich zuordnen?

### Kategoriensystem (Kodierleitfaden)


Grundlage ist die Forschungsfrage: *Welche Bedingungen und Handlungen erleben Kinder im Training als förderlich für ihr eigenes Kompetenzerleben?*


| Kategorie | Farbe | Definition | Ankerbeispiel |
|-----------|-------|------------|---------------|
| **K1: Rückmeldung durch die Trainerin** | Blau | Das Kind schildert eine Rückmeldung (Lob, Korrektur, Hinweis) der Trainerin und erlebt sie als förderlich für das eigene Können. | "Der Trainer hat gesagt, dass ich mich verbessert habe." |
| **K2: Passung der Aufgaben** | Orange | Aussagen dazu, wie gut die Übungsanforderungen zum eigenen Können passen (zu leicht, zu schwer, genau richtig). | "Die Übung war genau schwer genug, dass ich mich anstrengen musste." |


Sätze, die für die Forschungsfrage keine Rolle spielen, bleiben **unmarkiert**.


### Aufgabe


So geht's:


1. Wähle oben einen Markierstift (Blau = K1, Orange = K2).
2. Klicke auf einen Satz des Kindes, um ihn zu markieren. Erneutes Klicken entfernt die Markierung.
3. Die Fragen der Interviewerin sind nur Kontext und werden nicht codiert.
4. Klicke am Ende auf **Auswerten**, um die Musterlösung zu sehen.

var marks = {};
var tool = 'k1';
var evaluated = false;
function esc(t){
  return String(t).split('&').join('&amp;').split('<').join('&lt;').split('>').join('&gt;');

function segHtml(s){
  var m = marks[s.idx] || null;
  var cls = 'qia-seg';
  var st = '';
  var extra = '';
  if(m){
    var c = DATA.kategorien[m];
    st = ' style="background:' + c.farbe + ';border-bottom:3px solid ' + c.rand + '"';
    extra = '<sup class="qia-tag">' + c.kurz + '</sup>';
  }
  if(evaluated){
    cls += ' locked';
    var good = (m === (s.loesung || null));
    if(good){ extra += ' <span class="qia-ok">✓</span>'; }
    else if(s.grenzfall){ extra += ' <span class="qia-near">≈</span>'; }
    else { extra += ' <span class="qia-bad">✗</span>'; }
  }
  return '<span class="' + cls + '" data-seg="' + s.idx + '"' + st + '>' + esc(s.text) + '</span>' + extra + ' ';
}
function feedbackHtml(){
  var n = segs.length;
  var ok = 0;
  var near = 0;
  var items = '';
  for(var i = 0; i < n; i++){
    var s = segs[i];
    var m = marks[s.idx] || null;
    var sol = s.loesung || null;
    var good = (m === sol);
    if(good){ ok++; } else if(s.grenzfall){ near++; }
    var solName = sol ? DATA.kategorien[sol].name : 'keine Markierung (nicht relevant)';
    var myName = m ? DATA.kategorien[m].kurz : 'keine Markierung';
    var solStyle = sol ? ' style="background:' + DATA.kategorien[sol].farbe + ';border-bottom:3px solid ' + DATA.kategorien[sol].rand + '"' : '';
    var sym = good ? '<span class="qia-ok">✓</span>' : (s.grenzfall ? '<span class="qia-near">≈</span>' : '<span class="qia-bad">✗</span>');
    items += '<div class="qia-fbi">' +
      '<div>' + sym + ' <span class="qia-seg locked"' + solStyle + '>' + esc(s.text) + '</span></div>' +
      '<div class="qia-small">Deine Markierung: <b>' + esc(myName) + '</b> &middot; Musterlösung: <b>' + esc(solName) + '</b></div>' +
      '<div class="qia-expl">' + esc(s.erklaerung) + '</div>' +
      '</div>';
  }
  var head = '<div class="qia-score"><b>' + ok + ' von ' + n + '</b> Sätzen stimmen mit der Musterlösung überein.';
  if(near > 0){ head += ' Bei ' + near + ' Satz ist die Abweichung als Grenzfall vertretbar (≈).'; }
  head += ' Die Musterlösung ist ein Vorschlag und Anlass zum Vergleich im Plenum.</div>';
  return '<div class="qia-fb"><b>Musterlösung</b>' + head + items + '</div>';
}
function render(){
  var root = document.getElementById('qia-widget');
  if(!root) return;
  var html = '<div class="qia-card">';
  html += '<div class="qia-bar"><span class="qia-lbl">Markierstift:</span>';
  var keys = Object.keys(DATA.kategorien);
  for(var k = 0; k < keys.length; k++){
    var c = DATA.kategorien[keys[k]];
    html += '<button type="button" class="qia-tool' + (tool === keys[k] ? ' active' : '') + '" data-tool="' + keys[k] + '" style="background:' + c.farbe + ';border-color:' + c.rand + '">' + esc(c.name) + '</button>';
  }
  html += '<button type="button" class="qia-tool' + (tool === 'none' ? ' active' : '') + '" data-tool="none">Radierer</button>';
  html += '</div>';
  for(var t = 0; t < DATA.turns.length; t++){
    var turn = DATA.turns[t];
    if(turn.saetze){
      var line = '';
      for(var j = 0; j < turn.saetze.length; j++){ line += segHtml(turn.saetze[j]); }
      html += '<div class="qia-turn"><b>' + esc(turn.sprecher) + ':</b> ' + line + '</div>';
    } else {
      html += '<div class="qia-turn qia-int"><b>' + esc(turn.sprecher) + ':</b> ' + esc(turn.text) + '</div>';
    }
  }
  html += '<div class="qia-actions">';
  html += '<button type="button" class="qia-btn" data-act="check"' + (evaluated ? ' disabled' : '') + '>Auswerten</button>';
  html += '<button type="button" class="qia-btn" data-act="reset">Neu starten</button>';
  html += '</div>';
  if(evaluated){ html += feedbackHtml(); }
  html += '</div>';
  root.innerHTML = html;
}
function onClick(e){
  var el = e.target.closest('[data-tool],[data-seg],[data-act]');
  if(!el) return;
  if(el.hasAttribute('data-tool')){
    tool = el.getAttribute('data-tool');
    render();
  } else if(el.hasAttribute('data-seg')){
    if(evaluated) return;
    var i = parseInt(el.getAttribute('data-seg'), 10);
    if(tool === 'none' || marks[i] === tool){ marks[i] = null; }
    else { marks[i] = tool; }
    render();
  } else if(el.hasAttribute('data-act')){
    var act = el.getAttribute('data-act');
    if(act === 'check'){ evaluated = true; }
    if(act === 'reset'){ marks = {}; evaluated = false; }
    render();
  }
}
function init(tries){
  var root = document.getElementById('qia-widget');
  if(!root){
    if(tries > 0){ setTimeout(function(){ init(tries - 1); }, 250); }
    return;
  }
  addCss();
  render();
  if(window.qiaHandler){ root.removeEventListener('click', window.qiaHandler); }
  window.qiaHandler = onClick;
  root.addEventListener('click', onClick);
}
